Flashcard Review Activity

What is HTML?
HyperText Markup Language, the structure of web pages.
CSS stands for?
Cascading Style Sheets, used for styling web pages.
What is JavaScript?
A programming language that adds interactivity to websites.
Define Responsive Design
Design that adapts to different screen sizes and devices.
What is a CSS Grid?
A layout system for arranging elements in rows and columns.
Purpose of Flexbox?
To align and distribute space among items in a container.
What is a Transition?
A gradual change of CSS properties over time.
What is an Animation?
A sequence of keyframes that create movement or effects.
