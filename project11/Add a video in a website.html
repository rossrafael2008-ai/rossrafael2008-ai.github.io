How to Embed a Service‑Hosted Video Into Your Website

Student project tutorial with cropped screenshots, accurate steps, and external CSS styling

Overview

In this tutorial, you’ll learn to embed a video hosted on a service (e.g., YouTube) into your web page. Each step includes a screenshot, cropped tightly to the specific action. By the end, the selected video is embedded and functioning. Most styling is handled via an external stylesheet.

  • Directions: Clear, step‑by‑step text instructions.
  • Screenshots: One per step, tightly cropped.
  • Accuracy: Verified embed technique using iframe.
  • Styling: External CSS file, commented and clean.
  • Example video: Embedded and playable at the end.

Before you begin

  • Choose a family‑friendly video: No mature content or profanity.
  • Ensure embedding is enabled: Some uploaders restrict embeds.
  • Prepare to take screenshots: Use your OS screenshot tool and crop around the relevant UI.

If you’re unfamiliar with taking screenshots on your device, learn how first. Then proceed with the steps and capture each action.

Steps to embed a video from YouTube

Step 1: Open the video and click Share

Navigate to your chosen video’s page. Beneath the video player, select the Share button. This opens options for sharing and embedding.

Step 2: Select the Embed option

In the Share dialog, click Embed. You’ll see an iframe code snippet and optional settings like showing player controls or privacy‑enhanced mode.

Step 3: Copy the iframe embed code

Click Copy to grab the iframe code. Confirm it contains the https://www.youtube.com/embed/<VIDEO_ID> URL. If embedding is disabled for the video, choose a different one that allows embedding.

Step 4: Paste the iframe into your HTML

Open your project’s index.html. Locate the Embedded example section at the end and paste the iframe code inside the designated container. Save the file.

Step 5: Publish and test

Open the HTML file in your browser or deploy it (e.g., GitHub Pages). Confirm the player loads, controls work, and the video plays successfully within your page.
